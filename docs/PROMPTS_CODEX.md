# Prompt per Codex — immagini di Meteor Gods

Ogni prompt è **autonomo**: contiene già stile, contesto del gioco e percorso dove salvare il file.
Incollane **uno alla volta** in Codex, dentro la cartella del progetto `Meteors-God`. Le immagini finiscono in `art/`.
Non serve incollare altro prima. Tutte le immagini vengono generate **senza sfondo** (PNG trasparente).

Quando hai finito, carica le immagini su GitHub così posso guardarle:
`git add art` → `git commit -m "art"` → `git pull --rebase` → `git push`.

---
